# 🤖 AI HR Platform

> Автоматизированная система подбора персонала с ИИ-квалификацией кандидатов и мультиплатформенной интеграцией

## 📋 Описание

Платформа для автоматизации процессов рекрутинга, объединяющая несколько HR-площадок и ИИ-квалификацию в единую систему. Боты взаимодействуют с кандидатами на Avito и hh.ru, автоматически оценивают соответствие критериям вакансий, назначают собеседования и синхронизируют данные с CRM-системой Talantix.

## ⚙️ Технологии

| Компонент | Решение |
|---|---|
| **Язык** | Python 3.11 |
| **Web-фреймворк** | FastAPI + uvicorn |
| **Telegram-бот** | aiogram 3.x |
| **База данных** | PostgreSQL (asyncpg + PgBouncer) |
| **ORM** | SQLAlchemy (async) |
| **Очереди задач** | RabbitMQ (aio-pika) |
| **Кэширование** | Redis |
| **ИИ / LLM** | OpenAI API (gpt-4o-mini, gpt-4o) |
| **Хранение знаний** | Google Docs / Sheets API |
| **Контроль версий** | Alembic (миграции БД) |

## 🏗 Архитектура

Система построена на **event-driven** архитектуре с асинхронной обработкой событий через RabbitMQ. Каждый компонент — независимый воркер, масштабируемый горизонтально:

```
┌──────────────────────────────────────────────────────┐
│                  FastAPI (Webhooks)                    │
│        /webhooks/avito  │  /health  │  Talantix       │
└──────────────────┬───────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────────┐
│                     RabbitMQ Queues                       │
│  avito_inbound │ hh_inbound │ engine_tasks │ services    │
└───┬────────────┬────────────┬─────────────┬──────────────┘
    │            │            │             │
    ▼            ▼            ▼             ▼
┌────────┐  ┌────────┐  ┌──────────┐  ┌────────────┐
│Connector│ │Connector│ │  Engine   │ │  Services  │
│  (Avito)│ │  (hh.ru)│ │  (AI)    │ │  (TG/Sheets│
└────────┘  └────────┘  └──────────┘  └────────────┘
                                    ┌────────────┐
                                    │ Scheduler  │
                                    │  (Cron)    │
                                    └────────────┘
```

### Компоненты

| Воркер | Назначение |
|---|---|
| **worker_main** | FastAPI-сервер приёма вебхуков, health-check, инициализация |
| **worker_connector** | Адаптеры для Avito и hh.ru, унификация событий |
| **worker_engine** | ИИ-движок: обработка диалогов, квалификация, анализ данных |
| **worker_services** | Telegram-бот, рассылка уведомлений, отчёты в Google Sheets |
| **worker_scheduler** | Цикличные задачи: напоминания, outbound-поиск, обновление базы знаний |

## ✨ Функционал

### 🤖 ИИ-квалификация кандидатов
Автоматический сбор и валидация данных (возраст, гражданство, готовность к оформлению), проверка по критериям работодателя через LLM. Детальная аналитика затрат на каждый запрос.

### 📅 Умное управление расписанием
Динамический календарь собеседований через Google Sheets, аудит дат с помощью LLM, генерация контекста на 21 день вперёд.

### 🔔 Система уведомлений
Двухуровневые напоминания кандидатам «молчунам» с учётом часовых поясов и тихого времени. Напоминания о предстоящих собеседованиях (за день и за 2 часа).

### 🔍 Outbound-поиск
Активный поиск кандидатов через Avito и hh.ru с параметрами из Google Таблиц. Автоматическая отправка приглашений на собеседование.

### 📚 База знаний
Централизованное управление промптами и инструкциями в Google Docs с кэшированием и автообновлением.

### 🔗 Интеграции

| Площадка | Формат | Описание |
|---|---|---|
| **Avito** | REST API + вебхуки | Мультиплатформенный коннектор |
| **hh.ru** | REST API | Мультиплатформенный коннектор |
| **Talantix** | GraphQL | Создание и управление кандидатами в CRM |
| **Google Sheets** | REST API | Аналитика и хранение данных |
| **Telegram** | Bot API | Интерфейс для рекрутеров |

## 📦 Структура проекта

```
app/
├── connectors/      # Адаптеры HR-площадок (Avito, hh.ru)

```
